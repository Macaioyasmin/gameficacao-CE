Editor do JogoComissão de Ética da Finep

Edite o jogo sem mexer no código

Abra o arquivo do jogo aqui. As falas, as imagens e os botões de escolha aparecem em campos de texto comuns. Quando terminar, você salva um arquivo novo, pronto para publicar.

Escolher o arquivo do jogo Clique aqui ou arraste o arquivo .Rhtml (ou .html) para esta área
  1. Abra o arquivo do jogo (por exemplo, jogo-etica-finep-v21.Rhtml).
  2. Edite os textos, as imagens e as escolhas nas abas acima.
  3. Clique em “Testar o jogo” para ver o resultado de verdade.
  4. Clique em “Salvar arquivo do jogo” para baixar a versão nova.

O arquivo original nunca é alterado. O editor sempre gera um arquivo novo, com “-editado” no nome.
